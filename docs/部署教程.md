# Go企业级分布式高可用秒杀系统 — Windows部署教程

## 环境要求
| 组件 | 版本 | 说明 |
|------|------|------|
| Go | 1.26.5+ | D:\Program Files\Go\ |
| Docker Desktop | 最新版 | 运行中间件集群 |

## 快速启动

### 1. 配置Go环境变量
```powershell
[Environment]::SetEnvironmentVariable('Path', 'D:\Program Files\Go\bin;' + [Environment]::GetEnvironmentVariable('Path', 'User'), 'User')
```
重启终端后生效。

### 2. 启动中间件集群
```bash
docker-compose up -d mysql-master mysql-slave redis-node1 redis-node2 redis-node3 rabbitmq etcd kafka
```

### 3. 初始化Redis Cluster
```bash
docker exec -it miaosha-redis-node1 redis-cli -a $REDIS_PASSWORD --cluster create 127.0.0.1:6379 127.0.0.1:6380 127.0.0.1:6381 --cluster-replicas 0
```

### 4. 编译运行
```bash
go mod tidy
go build -o miaosha-server.exe ./cmd/
.\miaosha-server.exe
```

### 5. 验证
```bash
curl http://localhost:8080/health
curl -X POST http://localhost:8080/api/v1/user/register -H "Content-Type: application/json" -d '{"username":"test","password":"your_password"}'
curl -X POST http://localhost:8080/api/v1/user/login -H "Content-Type: application/json" -d '{"username":"test","password":"your_password"}'
```

## Docker 一键部署（推荐）

```bash
# 1. 配置密码
cp .env.example .env
# 编辑 .env 修改所有 change_me_* 密码

# 2. 启动全栈
docker compose --env-file .env up -d

# 3. 查看状态
docker compose ps

# 4. 访问
# 前端: http://localhost
# Swagger: http://localhost:8080/swagger/index.html
```

## 常见问题

**Q: 端口冲突？**
```bash
netstat -ano | findstr "8080 3306 6379 5672 9090 3000"
# 停止占用进程或修改 docker-compose.yml 端口映射
```

**Q: Redis Cluster 初始化失败？**
确保至少 3 个 Redis 节点已启动，且密码正确。

**Q: 数据库连接失败？**
检查 config.yaml 中的密码是否与 docker-compose.yml 中一致。
