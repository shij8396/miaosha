# Go企业级分布式高可用秒杀系统 — Windows部署教程

## 环境要求
| 组件 | 版本 | 说明 |
|------|------|------|
| Go | 1.26.5+ | D:\Program Files\Go\ |
| Docker Desktop | 最新版 | 运行中间件集群 |

## 快速启动

### 1. 配置Go环境变量
```powershell
[Environment]::SetEnvironmentVariable('Path', 'D:\Program Files\Go\bin;' + [Environment]::GetEnvironmentVariable('Path', 'User'), 'User')
```
重启终端后生效。

### 2. 启动中间件集群
```bash
docker-compose up -d mysql-master mysql-slave redis-node1 redis-node2 redis-node3 rabbitmq etcd kafka
```

### 3. 初始化Redis Cluster
```bash
docker exec -it miaosha-redis-node1 redis-cli -a miaosha_redis_2026 --cluster create 127.0.0.1:6379 127.0.0.1:6380 127.0.0.1:6381 --cluster-replicas 0
```

### 4. 编译运行
```bash
go mod tidy
go build -o miaosha-server.exe ./cmd/
.\miaosha-server.exe
```

### 5. 验证
```bash
curl http://localhost:8080/health
curl -X POST http://localhost:8080/api/v1/user/register -H "Content-Type: application/json" -d '{"username":"test","password":"123456"}'
curl -X POST http://localhost:8080/api/v1/user/login -H "Content-Type: application/json" -d '{"username":"test","password":"123456"}'
```
