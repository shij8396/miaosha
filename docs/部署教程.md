# Go企业级分布式秒杀系统 — Docker一键部署教程

## 环境要求
| 组件 | 版本 | 说明 |
|------|------|------|
| Docker Desktop | 最新版 | 运行所有服务（无需安装 Go/Node.js/MySQL 等） |

## 一键部署

### Windows
双击项目根目录下的 **`一键部署.bat`**，等待自动完成。

### Mac / Linux
```bash
chmod +x deploy.sh && ./deploy.sh
```

### 手动
```bash
docker compose up -d
```

首次启动约 5-10 分钟（需拉取镜像并编译后端）。

## 多实例部署
```bash
docker compose up --scale miaosha-server=3 -d
```

## 停止系统
```bash
# 停止（保留数据）
docker compose down

# 彻底清除（含数据库）
docker compose down -v
```

## 常见问题

**Q: 端口冲突？**
修改 `docker-compose.yml` 中对应服务的 `ports` 映射。

**Q: 镜像拉取慢？**
配置 Docker 镜像加速器（阿里云/腾讯云等）。

**Q: 数据库连接失败？**
确认 `.env` 中密码与 `config/config.docker.yaml` 一致。
