# 秒杀系统生产环境部署指南

## 前提条件

| 组件 | 状态 | 说明 |
|------|------|------|
| 操作系统 | CentOS 7/8/9 或 Rocky Linux | SSH 可登录 |
| Nginx | ✅ 已安装 | 占用 80 端口 |
| MySQL | ✅ 已安装 | 3306 端口，已知 root 密码 |
| Redis | ✅ 已安装 | 6379 端口，已知密码 |
| Docker | ❓需检查 | `docker --version` |
| Docker Compose | ❓需检查 | `docker compose version` |

---

## 第一步：安装 Docker

```bash
# 检查是否已装 Docker
docker --version
docker compose version

# 如果没装，执行一键安装
curl -fsSL https://get.docker.com | bash
systemctl enable docker && systemctl start docker

# 安装 Docker Compose 插件
# CentOS/Rocky 用 dnf
dnf install -y docker-compose-plugin
# 或者手动安装
mkdir -p /usr/local/lib/docker/cli-plugins
curl -SL "https://github.com/docker/compose/releases/latest/download/docker-compose-linux-x86_64" -o /usr/local/lib/docker/cli-plugins/docker-compose
chmod +x /usr/local/lib/docker/cli-plugins/docker-compose

# 验证
docker compose version
```

---

## 第二步：上传项目代码

在本地 Windows PowerShell 执行：

```powershell
# 把项目上传到服务器 /opt 目录
scp -r "E:\TRAE SOLO CN\project\miaosha" root@你的服务器IP:/opt/

# 如果 scp 慢，可以用 rsync（推荐）
# rsync -avz --exclude='.git' --exclude='node_modules' --exclude='logs' /path/to/miaosha/ root@服务器IP:/opt/miaosha/
```

---

## 第三步：配置环境变量

```bash
# 登录服务器
ssh root@你的服务器IP

cd /opt/miaosha

# 复制环境变量模板
cp .env.production .env

# 编辑，填入你的实际密码
vi .env
```

**需要修改的项：**

```
MIAOSHA_MYSQL_PASSWORD=你的MySQL密码        # 必填
MIAOSHA_REDIS_PASSWORD=你的Redis密码        # 必填
RABBITMQ_PASSWORD=你想设置的MQ密码          # 必填
MIAOSHA_JWT_SECRET=任意随机长字符串          # 必填，建议32位以上
MIAOSHA_SERVER_SIGN_SECRET=任意随机长字符串  # 必填，建议32位以上
GRAFANA_PASSWORD=你想设置的Grafana密码       # 必填
```

生成随机字符串：
```bash
openssl rand -hex 16
```

---

## 第四步：初始化数据库

```bash
cd /opt/miaosha

# 登录 MySQL
mysql -u root -p
```

在 MySQL 命令行中执行：

```sql
CREATE DATABASE IF NOT EXISTS miaosha DEFAULT CHARSET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE miaosha;
SOURCE /opt/miaosha/scripts/init.sql;
```

验证：
```sql
SHOW TABLES;
-- 应该能看到 t_user, t_product, t_order_0 ~ t_order_15 等表
```

---

## 第五步：构建前端

```bash
cd /opt/miaosha/frontend

# 安装 Node.js（如果没有）
curl -fsSL https://rpm.nodesource.com/setup_20.x | bash -
yum install -y nodejs

# 安装依赖并构建
npm install --registry https://registry.npmmirror.com
npm run build

# 验证
ls -la dist/
```

---

## 第六步：构建并启动后端

```bash
cd /opt/miaosha

# 构建 Docker 镜像
docker compose -f docker-compose.prod.yml build miaosha-server

# 启动所有服务
docker compose -f docker-compose.prod.yml up -d

# 查看启动状态
docker compose -f docker-compose.prod.yml ps

# 查看日志（确认无错误）
docker compose -f docker-compose.prod.yml logs --tail 50
```

---

## 第七步：配置 Nginx 反向代理

```bash
# 复制 Nginx 配置到站点目录
cp /opt/miaosha/deploy/nginx.prod.conf /etc/nginx/conf.d/miaosha.conf

# 测试 Nginx 配置
nginx -t

# 重载 Nginx
systemctl reload nginx
```

---

## 第八步：开放防火墙端口

```bash
# CentOS/Rocky 使用 firewalld
firewall-cmd --permanent --add-port=80/tcp
firewall-cmd --permanent --add-port=3000/tcp
firewall-cmd --permanent --add-port=9091/tcp
firewall-cmd --permanent --add-port=15672/tcp
firewall-cmd --reload

# 或者临时关闭 firewalld（仅限测试）
systemctl stop firewalld
```

同时在**云服务商控制台**安全组中放行同样的端口。

## 第九步：验证部署

| 服务 | 地址 | 账号 |
|------|------|------|
| 秒杀系统 | http://服务器IP | admin / test123 |
| 后端健康检查 | http://服务器IP/health | - |
| API 测试 | http://服务器IP/api/v1/product/active | - |
| Grafana | http://服务器IP:3000 | 密码在 .env 中 |
| Prometheus | http://服务器IP:9091 | - |
| RabbitMQ | http://服务器IP:15672 | admin / MQ密码 |

### 测试命令

```bash
# 健康检查
curl http://localhost/health?type=readiness

# API 测试
curl http://localhost/api/v1/product/active

# 秒杀接口（需要先登录获取 token）
curl -X POST http://localhost/api/v1/seckill/path \
  -H "Authorization: Bearer <你的token>" \
  -d '{"product_id":1}'
```

## 常用运维命令

```bash
# 查看服务状态
docker compose -f docker-compose.prod.yml ps

# 查看后端日志
docker compose -f docker-compose.prod.yml logs -f miaosha-server

# 查看 RabbitMQ 日志
docker compose -f docker-compose.prod.yml logs -f rabbitmq

# 重启后端
docker compose -f docker-compose.prod.yml restart miaosha-server

# 停止所有服务
docker compose -f docker-compose.prod.yml down

# 重新构建并启动
docker compose -f docker-compose.prod.yml up -d --build

# 清理所有容器（保留数据卷）
docker compose -f docker-compose.prod.yml down
```

## 常见问题排查

### Q: 后端连不上 MySQL
```bash
# 测试 MySQL 连接
mysql -u root -p -e "SELECT 1"

# 检查 MySQL 是否允许本地连接
# my.cnf 中 bind-address 应为 127.0.0.1 或 0.0.0.0
```

### Q: 后端连不上 Redis
```bash
# 测试 Redis 连接
redis-cli -a 密码 PING

# 检查 Redis 是否允许本地连接
# redis.conf 中 requirepass 是否已设置
```

### Q: RabbitMQ 启动失败
```bash
# 查看日志
docker compose -f docker-compose.prod.yml logs rabbitmq

# 手动创建 vhost（如果需要）
docker exec -it miaosha-rabbitmq rabbitmqctl add_vhost /miaosha
docker exec -it miaosha-rabbitmq rabbitmqctl set_permissions -p /miaosha admin ".*" ".*" ".*"
```

### Q: 前端页面空白
```bash
# 检查 Nginx 是否正确指向 dist 目录
ls /opt/miaosha/frontend/dist/index.html

# 检查 Nginx 配置
nginx -t

# 查看 Nginx 错误日志
tail -f /var/log/nginx/error.log
```

### Q: API 返回 502
```bash
# 检查后端是否启动
docker compose -f docker-compose.prod.yml ps miaosha-server

# 查看后端日志
docker compose -f docker-compose.prod.yml logs --tail 50 miaosha-server

# 检查 Nginx upstream 配置
cat /etc/nginx/conf.d/miaosha.conf
# 确保 server 127.0.0.1:8080; 正确
```
