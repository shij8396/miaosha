# 秒杀系统 — 买家使用说明

## 前置要求

你只需要安装一个软件：**Docker Desktop**

- 下载地址：https://www.docker.com/products/docker-desktop
- Windows 用户安装后重启电脑即可

## 一键部署（3 步）

### Windows 用户

双击项目根目录下的 **`一键部署.bat`**，等待脚本自动完成。

### Mac / Linux 用户

在终端中执行：

```bash
chmod +x deploy.sh
./deploy.sh
```

### 手动部署

```bash
docker compose up -d
```

首次启动需要拉取镜像，约 5-10 分钟。看到 "部署完成" 提示即可。

1. 用 **admin** 登录 → 进入管理后台
2. 在「商品管理」中查看/上架秒杀商品

## 停止系统

```bash
docker compose down
```

如需彻底清除数据（含数据库）：

```bash
docker compose down -v
```

## 常见问题

**Q: 端口被占用怎么办？**

修改 `docker-compose.yml` 中的端口映射，例如将 `"80:80"` 改为 `"8080:80"`。

**Q: 镜像拉取太慢？**

配置 Docker 镜像加速器（阿里云/腾讯云等），网上搜索「Docker 镜像加速」即可。

**Q: 如何修改密码？**

编辑 `.env` 文件和 `config/config.docker.yaml` 中的密码字段，保持两边一致。

**Q: 支持多实例部署吗？**

支持。执行 `docker compose up --scale miaosha-server=3 -d` 即可启动 3 个后端实例，Nginx 自动负载均衡。
